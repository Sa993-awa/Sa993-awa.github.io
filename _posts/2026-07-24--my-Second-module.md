#### This module provided a comprehensive foundation in modern object-oriented software engineering, progressing from core principles to advanced architectural and development practices.

#### I began by consolidating the fundamentals of Object-Oriented Programming — inheritance, polymorphism, abstraction, and encapsulation — and applying them through classes, objects, and constructors in Python. I then explored the SOLID principles, learning to write code that is maintainable, extensible, and resistant to regression through disciplined design and refactoring.

#### The module's central focus was design patterns. I studied all three categories: creational patterns (Factory Method, Singleton, Builder, Prototype, Abstract Factory) for flexible object creation; structural patterns (Decorator, Adapter, Facade, Proxy, and others) for organising classes into scalable structures; and behavioural patterns (Strategy, Observer, Command, State, and more) for managing communication between objects. Implementing patterns such as Factory Method, Decorator, and Strategy in practice deepened my ability to select appropriate solutions for recurring design problems.

#### I subsequently addressed concurrency and parallelism, gaining practical experience with threads, synchronisation, race conditions, and deadlock prevention to build reliable, thread-safe applications. Secure coding practices taught me to treat security as a fundamental requirement, applying input validation, authentication, and robust exception handling to defend against common vulnerabilities such as injection and buffer overflow attacks.

#### The later units strengthened my software maintenance capabilities. I learned to identify code smells and apply refactoring techniques to reduce technical debt, and I examined object-oriented software architecture — comparing monolithic, layered, and microservices styles and evaluating trade-offs between scalability, security, and maintainability. I also adopted Test-Driven and Behaviour-Driven Development, along with unit testing, mocks, and Dependency Injection / Inversion of Control, to produce modular, testable, and reliable systems.

#### The module culminated in a Capstone Project, where I integrated these disciplines — design principles, patterns, secure coding, architecture, and testing — to design and implement a complete software solution.

### Key outcomes: I emerged from this module able to design software that is not merely functional, but maintainable, secure, scalable, and testable — equipped with the professional practices essential for real-world software engineering.
