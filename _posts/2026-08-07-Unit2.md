#### During this unit, I developed my understanding of the SOLID principles and how they improve object-oriented programming by making code more organised, maintainable, and easier to extend. The practical activities helped me understand the purpose of each principle, especially the Single Responsibility Principle (SRP), which showed me the importance of giving each class a clear and specific responsibility. For example, separating order management from payment and discount processing made the code structure clearer and easier to manage.

#### While developing the shopping system task, I faced some challenges caused by errors in my code, including using a class before defining it and a spelling mistake in the PercentageDiscount class name. Since Python is case-sensitive, these errors prevented the program from running correctly. By analysing the error messages and correcting my code, I improved my debugging skills and learned the importance of accurate naming and careful code organisation.

#### Overall, this unit strengthened my confidence in applying SOLID principles in Python projects. I now have a better understanding of how these principles help create cleaner, more flexible, and maintainable software designs.

from abc import ABC, abstractmethod

#Abstract base class defining the common interface for electronic devices 

class ElectronicDevice (ABC):
    @abstractmethod
    def turn_on(self):
        pass

    @abstractmethod
    def turn_off(self):
        pass

# Implementation 
class TV(ElectronicDevice):
    

    def turn_on (self):
        print("TV is  now ON")


    def  turn_off(self):
        print("TV is now OFF") 


class Radio(ElectronicDevice):
   
    def  turn_on(self):
        print("Radio is now ON")  

    def turn_off(self):
       print("Radio is now OFF")

#Remot control that can work with any ElectronicDevice

class RemoteControl:                   
    def __init__ (self,device:ElectronicDevice ):   
       self.device =device   

    def turn_on(self):
        self.device.turn_on()

    def  turn_off(self):
        self.device.turn_off() 


class AdvancedRemoteControl(RemoteControl):    # Ability to add extra function
      
      def stop_timer(self,hours):
         print(f"Dvice will turn off within {hours}hours")


if __name__=="__main__":
