### Factory method Design Pattern

```python
class Car (ABC):
    @abstractmethod
    def drive(self):
        pass

class Sedan (Car):
    def drive(self):
        print("Drive safely with Sedan!, Better fuel economy!,Easier parking!")

class SUV (Car):
    def drive (self):
        print("Stay calm!,Flexible seating,Sports gear")


class Hatchback(Car):
     def drive (self):
         print("Safety features,environmental benefits")  

class CarFactory(ABC):
    @abstractmethod
    def create_car(self):
        pass 


    def create_car(self):     
        car =self.create_car
        car.drive()


class SedanFactory(CarFactory):
    def create_car(self):
        return Sedan()     



class SUVFactory(CarFactory):
    def create_car(self):
        return SUV()       


class HatchbackFactory(CarFactory):
    def create_car(self):
      return Hatchback() 


if __name__ == "__main__":
     Factories = [SedanFactory(), SUVFactory() ,HatchbackFactory()]

     for factory in Factories:
          car = factory.create_car()
          car.drive()
```

#### In this code I used the Factory method Design Pattern. Firstly, I created an abstract Car class with different car types such as Sedan, SUV, and Hatchback that implement the drive() method differently. I then created an abstract CarFactory class to define how cars should be created. Each specific factory, such as HatchbackFactory and SUVFactory, creates its own type of car. Finaly, I used a list of factories to create and drive different cars without directly creating the car objects.
