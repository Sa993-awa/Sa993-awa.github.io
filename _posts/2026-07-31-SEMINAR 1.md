🟣 There are some examples of these concepts:

1. *Inheritance* :
 This occurs when a new class inherits from another class, allowing it to use of the attributes and functions exist in the original class.

 ```Python
class Birds:
    def make_noise(self):
        print ("Birds make_niose")

class sparrow(Birds):
    pass

sparrow = sparrow()
sparrow.make_noise()
```



2. *Abstraction* :
It means hiding complex details and exposing only the essential functions to the user.
In this Example, Car specifies that every car must have a drive() method, while the implementation details are defined by the subclasses.

```Python
from abc import ABC, abstractmethod

class Car(ABC):
    @abstractmethod
    def drive(self):
        pass

class KIA(Car):
    def drive(self):
      print("Driving KIA Safely")

car =KIA()
car.drive()
```



3. *Encapsulation* :
It means encapsulating data and its associated functions within a class and controlling access to the data. We used __balance to make the variable private, it also restrict direct access from outside the class.

```Python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance
```



4. *Polymorphism* :
It allows objects of different classes to be treated as objects of a common super class.

```Python
class Bird:
    def make_sound(self):
        print("chirping")

class Sparrow:
    def make_sound(self):
        print("twittering")

for animal in [Bird(), Sparrow()]:
    animal.make_sound()
```
