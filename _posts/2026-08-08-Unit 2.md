##### This week, I learned how the SOLID principles improve object-oriented programming by making code easier to maintain, extend, and understand. The practical exercises helped me see that each principle has a specific purpose. For example, the Single Responsibility Principle (SRP) taught me that each class should have only one responsibility, such as separating the Order class from payment and discount processing.

##### During the shopping system task, I encountered errors because I had not defined the Discount Method class before using it, and I misspelled ( Percentage Discount). Since Python is case-sensitive, this caused my program to fail. After reviewing the error messages and correcting my code, I gained a better understanding of debugging and the importance of careful class definitions and naming. Overall, this unit increased my confidence in applying SOLID principles to write cleaner and better-structured Python code.
